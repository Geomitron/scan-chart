Each instrument section holds one track: the notes, modifiers and phrases of one instrument at one difficulty.

```text
[ExpertSingle]
{
  768 = N 0 0
  768 = N 1 0
  960 = N 2 192
  960 = S 2 768
  1152 = N 3 0
}
```

## Section names

A section's name is a difficulty followed by an instrument, such as `ExpertSingle` for Expert guitar. The difficulties are `Easy`, `Medium`, `Hard` and `Expert`.

| Instrument in the name | Instrument | Kind |
|---|---|---|
| `Single` | Lead guitar | 5-fret |
| `DoubleGuitar` | Co-op guitar | 5-fret |
| `DoubleBass` | Bass guitar | 5-fret |
| `DoubleRhythm` | Rhythm guitar | 5-fret |
| `Keyboard` | Keys, played on a guitar controller | 5-fret |
| `Drums` | Drums | Drums |
| `GHLGuitar` | 6-fret guitar | 6-fret |
| `GHLBass` | 6-fret bass | 6-fret |
| `GHLRhythm` | 6-fret rhythm guitar | 6-fret |
| `GHLCoop` | 6-fret co-op guitar | 6-fret |
| `GHLKeys` | 6-fret keys | 6-fret |

A scanner matches names exactly, in the letter case shown.

**Edge case: names close to these.** Clone Hero checks only some of a name's characters, so it reads a few other names as instrument sections: `[ExpertSingl]` is Expert guitar there. YARG's chart loader adds `[ExpertDoubleDrums]` to Expert drums when the file also has `[ExpertDrums]`. YARG's song list and scan-chart match names exactly.

## Notes

A note is an `N` event:

```text
<tick> = N <value> <length>
```

The value says which note it is, and depends on the kind of instrument. The length is the note's sustain, in ticks: the note is held from its tick to `tick + length`. A length of 0 means no sustain.

### 5-fret

| Value | Note |
|---|---|
| `0` | Green |
| `1` | Red |
| `2` | Yellow |
| `3` | Blue |
| `4` | Orange |
| `7` | Open: strummed with no fret held |

`N 5` and `N 6` are modifiers, not notes. See [Note modifiers](/chart/modifiers).

### 6-fret

The 6-fret frets are in two rows: three black frets on top and three white frets below them.

| Value | Note |
|---|---|
| `0` | White 1 |
| `1` | White 2 |
| `2` | White 3 |
| `3` | Black 1 |
| `4` | Black 2 |
| `7` | Open |
| `8` | Black 3 |

`N 5` and `N 6` are modifiers, as on 5-fret. See [Note modifiers](/chart/modifiers).

### Drums

| Value | 4-lane and pro | 5-lane |
|---|---|---|
| `0` | Kick | Kick |
| `1` | Red | Red |
| `2` | Yellow | Yellow |
| `3` | Blue | Blue |
| `4` | Green | Orange |
| `5` | Green tom. See [Drum types](/chart/drums#drum-types) | Green |
| `32` | Double kick | Double kick |

[Drums](/chart/drums) gives the kinds of drum chart, and the modifiers for cymbals, accents, ghosts and flams.

## Notes at one tick

- Notes of different values at one tick form a chord. Each note of a chord keeps its own length, so a chord's sustains can end at different ticks.
- An open note may be in a chord with fret notes. The player holds the fret notes and strums.

## Tracks

A section is a track only if it holds at least one note. [How notes resolve](/chart/note-resolution) says how a scanner turns a section's notes into the notes a player plays.

**Edge case: a section without notes.** A section with only modifiers, phrases or text events is allowed, for example while a charter copies phrases to every difficulty before charting its notes. It isn't a track: a scanner doesn't list it, and it gets no hash. scan-chart reports it as a warning.

## Ignored

- **An `N` value that the tables don't list** for the section's instrument, such as `N 8` in a 5-fret section.
- **A section with any other name.** Older games used names such as `ExpertSingleBass` and `ExpertDoubleDrums`.

## Invalid forms

<Accordion title="Two notes of one value at one tick">
Clone Hero and scan-chart use the note with the longer sustain. YARG uses the one written first. On guitar, it counts the two as a chord when it decides strums and HOPOs, so the note is a strum there unless a modifier changes it. When scan-chart saves an edited song, it removes a line written twice, and keeps notes of different lengths as written.
</Accordion>
