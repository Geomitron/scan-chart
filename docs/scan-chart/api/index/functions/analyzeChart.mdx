---
title: "analyzeChart()"
---

```ts
function analyzeChart(chart, options?): {
  issues: readonly Issue[];
  stats: ChartStats;
};
```

A gameplay chart's issues and statistics. The issues include the chart file's nonstandard spellings: compatibility
issues always, and style notes when `styleNotes` asks for them. A check with a charting recommendation also reports,
at the `recommendation` severity, what misses the recommendation but passes the check.

## Parameters

| Parameter | Type |
| ------ | ------ |
| `chart` | [`GameplayChart`](/scan-chart/api/index/interfaces/GameplayChart) |
| `options?` | \{ `styleNotes?`: `boolean`; \} |
| `options.styleNotes?` | `boolean` |

## Returns

```ts
{
  issues: readonly Issue[];
  stats: ChartStats;
}
```

| Name | Type |
| ------ | ------ |
| `issues` | readonly [`Issue`](/scan-chart/api/index/interfaces/Issue)[] |
| `stats` | [`ChartStats`](/scan-chart/api/index/interfaces/ChartStats) |
