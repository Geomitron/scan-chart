---
title: "ChartSectionToken"
---

One `[name] { ... }` section of a `.chart` file. `bodyStart` and `bodyEnd` are offsets in the decoded text.

## Properties

| Property | Modifier | Type |
| ------ | ------ | ------ |
| <a id="property-bodyend"></a> `bodyEnd` | `readonly` | `number` |
| <a id="property-bodystart"></a> `bodyStart` | `readonly` | `number` |
| <a id="property-name"></a> `name` | `readonly` | `string` |
