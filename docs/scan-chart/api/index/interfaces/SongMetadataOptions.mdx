How to read metadata.

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="property-removestyletags"></a> `removeStyleTags?` | `readonly` | `boolean` | Remove style tags, such as `<b>` and `<color=#AEFFFF>`, from text values, for plain-text display. Default: `false`. |
