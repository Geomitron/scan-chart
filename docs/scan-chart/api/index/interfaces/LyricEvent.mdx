## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-flags"></a> `flags` | `number` | bitmask of `lyricFlags`, which define the modifiers that apply to this lyric event. (nonPitched, lenientScoring, hyphenateWithNext, etc...) |
| <a id="property-mstime"></a> `msTime` | `number` | Time of the lyric event, in ms. |
| <a id="property-text"></a> `text` | `string` | The text content of the lyric event. Often will be a single lyric syllable. |
| <a id="property-tick"></a> `tick` | `number` | Tick position of the lyric event. |
