---
title: "SongFile"
---

One file of a song folder, as the caller has it: its bytes, or a byte source. scan-chart never reads the disk.

## Properties

| Property | Modifier | Type |
| ------ | ------ | ------ |
| <a id="property-data"></a> `data` | `readonly` | `Uint8Array`\<`ArrayBufferLike`\> \| [`ByteSource`](/scan-chart/api/index/interfaces/ByteSource) |
| <a id="property-filename"></a> `fileName` | `readonly` | `string` |
