title: "AuthoredElement"

An authored element an edit can move or remove: an event, text event, tempo or time signature.

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="property-length"></a> `length?` | `readonly` | `number` | Absent for an element written as one event or line with no length, such as a tempo. |
| <a id="property-source"></a> `source` | `readonly` | [`AuthoredSource`](/scan-chart/api/index/type-aliases/AuthoredSource) | - |
| <a id="property-tick"></a> `tick` | `readonly` | `number` | - |
