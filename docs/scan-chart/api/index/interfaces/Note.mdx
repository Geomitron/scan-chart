---
title: "Note"
---

One lane or fret at one tick, with its sustain and its note modifiers.

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="property-flags"></a> `flags` | `readonly` | `number` | The note modifiers: a bitmask of `noteFlags` (strum, HOPO, tap, cymbal, accent and so on). |
| <a id="property-length"></a> `length` | `readonly` | `number` | - |
| <a id="property-mslength"></a> `msLength` | `readonly` | `number` | - |
| <a id="property-mstime"></a> `msTime` | `readonly` | `number` | - |
| <a id="property-tick"></a> `tick` | `readonly` | `number` | - |
| <a id="property-type"></a> `type` | `readonly` | [`NoteType`](/scan-chart/api/index/type-aliases/NoteType) | The lane or fret: a value of `noteTypes`. |
