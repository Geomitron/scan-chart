```ts
function calculateCanonicalChartDuration(chart): CanonicalChartDuration;
```

Mirrors StrikeCore `Song.GetLastTick()` and `Song.TickPositionToTime()` at
song speed 1.0. Only regular notes in `Track.Notes` contribute to the last
tick; vocal-note collections and chart events do not.

## Parameters

| Parameter | Type |
| ------ | ------ |
| `chart` | [`ParsedChartFile`](/scan-chart/api/competitive/interfaces/ParsedChartFile) |

## Returns

[`CanonicalChartDuration`](/scan-chart/api/competitive/interfaces/CanonicalChartDuration)
