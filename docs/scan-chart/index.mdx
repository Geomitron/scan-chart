---
title: "scan-chart"
description: "The TypeScript library that reads and writes song folders to this specification."
---

scan-chart reads and writes song folders to this specification. It runs in Node and in browsers, and you use it to:

- show a song's metadata without reading its notes;
- check a chart for problems and get its statistics;
- calculate the hashes that Clone Hero's leaderboards use to tell charts apart;
- edit a chart, save it, and convert it between `.chart` and `.mid`.

```sh
npm install scan-chart
```

The [README](https://github.com/Geomitron/scan-chart#readme) is the guide to using it, with an example for each of these tasks. The [release notes](https://github.com/Geomitron/scan-chart/blob/master/CHANGELOG.md) list the changes in each version.
